# 三国人物猜猜猜 - 网页版

## 功能特点

- 精美的网页界面
- 支持创建房间和加入房间
- 实时猜测提示
- 人物列表浏览
- 响应式设计，支持手机和电脑

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动服务器

```bash
python run_web.py
```

### 3. 访问游戏

在浏览器中访问：http://localhost:5000

## 游戏玩法

1. **创建房间**：点击"创建房间"，输入你的名字，系统会生成房间码
2. **加入房间**：点击"加入房间"，输入你的名字和房间码
3. **开始游戏**：进入游戏界面后，输入人物名字进行猜测
4. **查看提示**：系统会显示属性对比结果和当前限定范围
5. **猜对获胜**：猜中系统预设的人物即获胜

## 界面说明

### 主菜单
- 创建房间：创建新的游戏房间
- 加入房间：加入已有的游戏房间
- 人物列表：查看所有可猜测的人物

### 游戏界面
- 房间码：显示当前房间码
- 猜测输入：输入人物名字进行猜测
- 提示区域：显示猜测结果和提示信息
- 猜测记录：显示所有猜测历史

### 人物列表
- 按势力分组显示所有人物
- 支持搜索功能

## 技术栈

- 后端：Python Flask
- 前端：HTML5 + CSS3 + JavaScript
- 数据库：SQLite

## 局域网联机

如果你想和朋友在同一局域网内游戏，可以：

1. 启动服务器时使用 `host='0.0.0.0'`（已默认配置）
2. 查看你的IP地址：`ipconfig`（Windows）或 `ifconfig`（Mac/Linux）
3. 让朋友在浏览器中访问：`http://你的IP地址:5000`

## 常见问题

### Q: 为什么无法访问？
A: 请确保：
- 服务器已启动
- 防火墙没有阻止5000端口
- 使用正确的地址访问

### Q: 如何和朋友远程游戏？
A: 可以使用内网穿透工具，如：
- ngrok
- frp
- localtunnel

### Q: 数据库在哪里？
A: 数据库文件位于 `game/game.db`，首次运行时会自动创建。
