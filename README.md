# 猜一下 - 游戏平台

一个有趣的猜谜游戏平台，包含多个小游戏！

## 游戏列表

### 1. 三国人物
猜出系统预设的三国历史人物，通过属性对比缩小范围。

### 2. 世界国家
猜出系统预设的国家，通过经纬度、人口、面积等信息推理。

### 3. 当代人物（即将推出）

## 快速开始

### 安装依赖
```bash
pip install flask
```

### 启动游戏
```bash
cd game
python run_web.py
```

然后在浏览器中访问 http://localhost:8080

## 游戏玩法

### 三国人物

1. 点击"三国人物"进入游戏
2. 系统会提示：国家名称 X个字，首都名称 X个字
3. 输入人物名字进行猜测
4. 根据提示缩小范围：
   - 姓/名：一致/不一致
   - 字：一致/不一致/有相同的字
   - 生卒年：更早/更晚/接近
   - 势力：一致/不一致
   - 身份：一致/不一致
   - 特质：列出相同特质

### 世界国家

1. 点击"世界国家"进入游戏
2. 系统会提示：国家名称 X个字，首都名称 X个字
3. 输入国家名称进行猜测
4. 根据提示缩小范围：
   - 经度：比该国更东/更西/接近
   - 纬度：比该国更北/更南/接近
   - 首都距离：X公里
   - 人口：比该国更多/更少/接近
   - 面积：比该国更大/更小/接近
   - GDP排名：比该国更高/更低/接近
