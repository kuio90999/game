# 三国人物猜猜猜

一个基于三国历史人物的猜谜对战游戏，支持单人练习或两人对战，猜出系统预设的三国人物！

## 功能特点

- 100+三国历史人物数据库
- 支持单人练习或两人在线对战
- 详细的属性对比提示
- 人物关系系统
- 命令行和HTTP API两种游戏方式

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 初始化数据

```bash
python run.py
```

这会自动初始化数据库并导入三国人物数据，然后启动命令行游戏界面。

### 3. 使用HTTP API

如果你想使用HTTP API方式游戏，可以启动API服务器：

```bash
python api.py
```

服务器会在 http://localhost:5000 启动。

## 游戏方式

### 命令行方式

运行 `python run.py` 后，按照提示操作：

1. **创建房间**：输入你的名字，系统会生成房间码并直接开始游戏
2. **加入房间**（可选）：朋友可以输入房间码加入对战
3. **猜测人物**：输入三国人物名字进行猜测
4. **查看提示**：系统会返回属性对比结果

### HTTP API方式

启动API服务器后，可以使用以下接口：

#### 创建房间
```bash
POST /api/create
{
  "player": "玩家名称"
}
```

#### 加入房间（可选）
```bash
POST /api/join
{
  "room_code": "房间码",
  "player": "玩家名称"
}
```

#### 猜测人物
```bash
POST /api/guess
{
  "room_code": "房间码",
  "player": "玩家名称",
  "character_name": "人物名称"
}
```

#### 获取房间信息
```bash
GET /api/room/{room_code}
```

#### 获取人物列表
```bash
GET /api/characters
```

## 人物属性

每个人物包含以下属性：

- **姓**：姓氏
- **名**：名字
- **字**：表字（可为空）
- **生年**：出生年份
- **卒年**：去世年份
- **出生地**：籍贯
- **朝代**：所处朝代
- **势力**：所属势力
- **身份**：帝王、诸侯、武将、统帅、文臣、谋士、女性、民间、官宦
- **特质**：仁厚、峻厉、莽撞、持重、桀骜、谦虚、圆滑、好名、出世、忠义、善谋、善武、善政、善文、善辩

## 对比提示规则

猜测错误时，系统会返回以下提示格式：

```
猜测：曹操
------------------------------
姓：曹  不一致
名：曹操  不一致
字：孟德  有相同的字：德
生年：155  更早
卒年：220  更晚
出生地：安徽亳州  同省：安徽
势力：曹魏  一致
身份：帝王  不一致
特质：善谋·善文·善政·世家大族  相同：善谋、善政
```

提示说明：
- 姓：列出具体姓氏，显示"一致"或"不一致"
- 名：列出具体名字，显示"一致"或"不一致"
- 字：列出具体字，显示"一致"或"有相同的字：X"
- 生年：列出具体年份，显示"一致"、"更早"或"更晚"
- 卒年：列出具体年份，显示"一致"、"更早"或"更晚"
- 出生地：列出具体地点，显示"同省：X"或"不同省"
- 势力：列出具体势力，显示"一致"或"不一致"
- 身份：列出身份数，显示"一致"或"不一致"
- 特质：列出所有特质，显示"相同：X、Y"或"无相同"
- 关系：如果存在关系会提示

## 人物关系

系统维护了部分人物之间的关系：

- 友好：盟友、主臣、亲属等
- 敌对：敌人、对手等

当猜测的人物与答案人物有关系时，会特别提示。

## 数据库

游戏使用SQLite数据库，包含以下表：

- `characters`：人物表
- `relations`：关系表
- `rooms`：房间表
- `guesses`：猜测记录表

## 开发说明

### 项目结构

```
game/
├── run.py          # 主启动脚本
├── cli.py          # 命令行客户端
├── api.py          # HTTP API接口
├── game.py         # 游戏核心逻辑
├── database.py     # 数据库操作
├── data.py         # 人物数据
├── init_data.py    # 数据初始化
├── test_api.py     # API测试脚本
├── requirements.txt
└── README.md
```

### 扩展人物数据

要添加新人物，编辑 `data.py` 文件中的 `CHARACTERS` 列表，然后重新运行 `init_data.py`。

### 扩展关系数据

要添加新关系，编辑 `data.py` 文件中的 `RELATIONS` 列表，然后重新运行 `init_data.py`。
